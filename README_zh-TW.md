# NTOU 場地借用小幫手

這是一個專為國立臺灣海洋大學（NTOU）社團系統設計的 Chrome 瀏覽器擴充功能，用於自動化場地借用流程。

## 功能特色
- **自動填表**：自動填寫社團名稱、負責人、電話、信箱與活動名稱。
- **多日連續借用**：只需設定開始與結束日期，系統便會自動逐日送出申請。
- **時段選擇**：支援選擇特定活動時段（例如下午五點到晚上八點）。
- **背景自動化執行**：擴充功能會在背景自動控制分頁導航，完成表單填寫與送出。

## 安裝方式



### 本地端安裝（開發者模式）
1. 下載或 Clone 此專案到您的電腦。
2. 打開 Google Chrome 瀏覽器，並前往 `chrome://extensions/`。
3. 開啟右上角的**開發者模式**。
4. 點擊左上角的**載入未封裝項目**，然後選擇此專案所在的資料夾。
5. 安裝完成後，擴充功能圖示將出現在您的瀏覽器工具列中。

## 使用說明
1. 先登入 [海洋大學社團系統](https://sclub.ntou.edu.tw/)。
2. 點擊瀏覽器工具列上的「NTOU 場地借用小幫手」圖示。
3. 在彈出的視窗中填寫借用資訊：開始日期、結束日期、場地、社團名稱、負責人、電話、信箱，並勾選借用時段。
4. 點擊**開始自動借用**按鈕。
5. 擴充功能將會自動接管頁面並依序填寫、送出每一天的申請，請耐心等待進度條跑完。

## 權限說明
- `activeTab`：用來確認目前分頁是否為海大社團系統網頁。
- `storage`：用來記憶您填寫過的聯絡資訊與社團資料，下次開啟時自動帶入。
- `scripting`：用來在網頁上執行自動填表與送出的腳本。
