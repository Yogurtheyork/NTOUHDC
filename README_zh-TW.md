# NTOU 場地借用小幫手

這是一個專為國立臺灣海洋大學（NTOU）社團系統設計的 Chrome 瀏覽器擴充功能，用於自動化場地借用流程。

## 功能特色
- **自動填表**：自動填寫社團名稱、負責人、電話、信箱與活動名稱。
- **多日連續借用**：只需設定開始與結束日期，系統便會自動逐日送出申請。
- **時段選擇**：支援選擇特定活動時段（例如下午五點到晚上八點）。
- **背景自動化執行**：擴充功能會在背景自動控制分頁導航，完成表單填寫與送出。

## 安裝方式

### 一般使用者（不需要寫程式）
1. 到 [Releases 頁面](https://github.com/Yogurtheyork/NTOUHDC/releases/latest) 下載 `NTOU-Helper-Local.zip`。
2. 解壓縮，把資料夾放在不會被刪掉的地方（例如「文件」）。
3. 打開 Chrome，前往 `chrome://extensions/`，開啟右上角的**開發人員模式**。
4. 點擊**載入未封裝項目**，選擇剛剛解壓縮出來的資料夾（裡面直接有 `manifest.json`）。
5. 完成！詳細圖文步驟與常見問題請看 zip 裡的 `安裝說明.html`。

Microsoft Edge 使用者：網址改成 `edge://extensions/`，按鈕名稱是「載入解壓縮」。

### 開發者：從原始碼建置
```bash
npm install
npm run build   # 編譯 TypeScript、複製靜態檔、產生圖示，並輸出 NTOU-Helper-Local.zip
```
建置完成後，`dist/` 就是可直接載入的擴充功能資料夾，`NTOU-Helper-Local.zip` 則是可以直接發給別人的壓縮檔。

## 使用說明
1. 先登入 [海洋大學社團系統](https://sclub.ntou.edu.tw/)。
2. 點擊瀏覽器工具列上的「NTOU 場地借用小幫手」圖示。
3. 在彈出的視窗中填寫借用資訊：開始日期、結束日期、場地、社團名稱、負責人、電話、信箱，並勾選借用時段。
4. 點擊**開始自動借用**按鈕。
5. 擴充功能將會自動接管頁面並依序填寫、送出每一天的申請，請耐心等待進度條跑完。

## 權限說明
- `activeTab`：用來確認目前分頁是否為海大社團系統網頁。
- `storage`：用來記憶您填寫過的聯絡資訊與社團資料，下次開啟時自動帶入。
- `scripting`：用來在網頁上執行自動填表與送出的腳本。
