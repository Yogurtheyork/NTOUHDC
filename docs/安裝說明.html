NTOU 場地借用小幫手　安裝說明

這個資料夾就是擴充功能本體，不用安裝其他軟體。照下面步驟做一次，之後打開瀏覽器就能直接用。

一、解壓縮

  1. 在 NTOU-Helper-Local.zip 上按右鍵 →「全部解壓縮」（Mac 直接點兩下）。
  2. 把解壓出來的資料夾放在「不會被刪掉」的地方，例如「文件」或「桌面」。
之後請不要移動或刪除這個資料夾，否則擴充功能會失效。

二、在 Chrome 安裝

  1. 打開 Chrome，在網址列輸入 chrome://extensions 後按 Enter。
  2. 把右上角的「開發人員模式」開關打開。
  3. 點左上角出現的「載入未封裝項目」按鈕。
  4. 選擇剛剛解壓縮出來的資料夾（裡面要看得到 manifest.json），按「選擇資料夾」。
  5. 完成！清單裡會出現「NTOU 場地借用小幫手」。
用 Microsoft Edge 的話步驟相同，網址改成 edge://extensions，按鈕名稱是「載入解壓縮」。

三、把圖示釘在工具列（建議）

點瀏覽器右上角的「拼圖」🧩 圖示，找到「NTOU 場地借用小幫手」，按旁邊的「圖釘」，圖示就會固定在工具列上。

四、開始使用

  1. 先到 海大社團系統 登入。
  2. 登入後，點工具列上的「NTOU 場地借用小幫手」圖示。
  3. 填寫開始／結束日期、場地、社團名稱、負責人、電話、信箱，並勾選要借用的時段。
  4. 按「開始自動借用」。
  5. 擴充功能會自動一天一天填表、送出。請耐心等進度條跑完，過程中不要關閉或切換那個分頁。
聯絡資料會自動記住，下次打開就不用再填。

五、常見問題

載入時出現「manifest file is missing or unreadable」
選錯資料夾了。請確認你選的資料夾裡面直接就有 manifest.json，不是它的上一層或下一層。
按「開始自動借用」沒反應
請先確認已經登入社團系統，而且目前分頁是 sclub.ntou.edu.tw。
Chrome 跳出「停用開發人員模式的擴充功能？」
按「取消」或「保留」即可，這是本機安裝擴充功能的正常提示。
擴充功能不見了
通常是解壓縮的資料夾被移動或刪除。請重新解壓縮，再做一次「二」的步驟。
自動化跑到一半停了
可能是社團系統網頁改版，請到 GitHub 回報。
